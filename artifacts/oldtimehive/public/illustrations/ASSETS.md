# Oldtime tools artwork

App-owned artwork, not copied from reference screenshots. Active Settings illustrations are transparent cutouts without background panels.

- `oldtime-insights.png`: stopwatch, red chart columns and feather.
- `oldtime-help.png`: lifebuoy, conversation bubble and feather.
- `oldtime-blue-badge.png`: the user's supplied blue check artwork.
- `oldtime-{neighbors,conversation,celebration,community,lineup}.png`: cutouts of the user's supplied cartoon characters.

These files are bundled as static assets using the artifact base URL, not temporary URLs or external hosts. Supplied originals and original generated PNGs are retained in attached_assets. Earlier JPEG/WebP versions are inactive source backups.
